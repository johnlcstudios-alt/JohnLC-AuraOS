Questions, answered.

Ask on GitHub
Is AuraOS a Linux distribution or a new operating system?

No. JohnLC AuraOS is a desktop shell — an Electron app that runs full screen on top of Windows, macOS or Linux. It is not a bootloader and it does not replace your OS.

Does it replace Windows?

No. AuraOS runs as an application on your existing desktop. Your files, drives and installed programs stay exactly where they are.

Why does Windows SmartScreen warn me?

The installer is not code-signed. SmartScreen may show a warning for a new or unsigned build. Choose More info → Run anyway if you downloaded it from this repository or built it yourself.

Does AuraOS start automatically when I sign in?

Only if you turn it on. Open Settings → System → Startup and enable Open at login. The installer never enables auto-start for you, and turning the toggle off removes the entry immediately.

How do I uninstall it?

Open Windows Settings → Apps → Installed apps, find JohnLC AuraOS, and choose Uninstall. Your profile and files are left in place.

Where is my configuration stored?

On Windows, preferences live in %APPDATA%\JohnLC AuraOS\auraos-config.json. The browser preview uses localStorage under the same AuraOS keys.

Can I build it from source?

Yes. Clone the repository, run npm install, then npm run dev or npm run dist. The README has the full setup, build and troubleshooting guide.

Other platforms

macOS and Linux run from source.

The Windows installer is the only prebuilt package today. On macOS and Linux, clone the repository and run the one-line installer.
