The details

A desktop that feels familiar, not generic.

Every surface is designed to feel at home on day one. The window manager, search and system panels are built from scratch — no stock UI kit, no browser tabs pretending to be apps.

Window management, from scratch

Drag, resize and stack windows with real focus and z-index. Hover the maximise button for Snap Layouts, or drag to any edge for quarters, thirds and two-thirds regions.

8-way resizeSnap AssistGenie minimize
Snap Layouts

Two shells. One OS.

Switch between a floating macOS Dock with a Top Bar and a centred Windows 11 Taskbar with Start and Quick Settings. Your windows come along.

macOSWindows 11

Spotlight, everywhere.

Search apps, settings, files and places from one command palette. Do maths inline, preview with Space, and fall back to the web without leaving the keyboard.

Search AuraOS…⌘Space

Real files. Real terminal.

Browse your actual disk, preview images and text, run real shell commands in tabs, and keep using the tools you already trust.

✓ working tree clean

Make it yours.

Light, dark or auto. Ten accent colours, six wallpapers, custom images, translucency, reduced motion and a window chrome you choose.

Mission Control & Spaces

See every window at once, create virtual desktops, and move work between them. F3 opens Mission Control; the pager keeps your spaces one click away.
